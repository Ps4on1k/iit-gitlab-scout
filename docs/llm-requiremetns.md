1. Статистику по контрибьюторам:

   - определить основной язык репозитория
   - найти все файлы зависимостей (package.json, go.mod, requirements.txt и т.д.)
   - распарсить их и вернуть плоский список зависимостей с версиями

УСЛОВИЯ:

- Доступ к GitLab — через персональный токен (private token)
- Работать с любым публичным или приватным репозиторием (но токен даёт доступ)

ОСОБЫЕ ТРЕБОВАНИЯ ДЛЯ ЭТОЙ ЗАДАЧИ:
